## 1. Background & Root Cause Analysis

### 1.1 Problem Statement & Context
The reinforcement learning trading environment in SynapseX has been upgraded to support a 3-state discrete position mechanism:
$$
\text{position} \in \{-1, 0, 1\} \quad (\text{Short} = -1, \text{Flat} = 0, \text{Long} = 1)
$$
(Refer to [`spec/issue_short_selling_mechanism.md`](file:///home/b0457812963/Mamba3RL/SynapseX/spec/issue_short_selling_mechanism.md)).

However, the core performance counting function [`logic_order`](file:///home/b0457812963/Mamba3RL/SynapseX/Brain/Count/nb.py#L336-L469) in [`Brain/Count/nb.py`](file:///home/b0457812963/Mamba3RL/SynapseX/Brain/Count/nb.py) is currently hardcoded for long-only trading (`direction = "buyonly"`). Its state transition only recognizes:
```python
if current_order == 1:
    marketpostion = 1
if current_order == -1:
    marketpostion = 0
```
As a result:
- When a model executes a short position (`-1`), `logic_order` incorrectly treats it as flattening to 0 or completely ignores short-selling trades.
- Slippage, fees, unrealized PnL, and realized PnL for short trades are either zero or calculated in the wrong direction (e.g. price drops being counted as losses instead of gains).
- Backtesting reports generated by `Backtest.py` fail to accurately reflect model performance when short trades are executed.

### 1.2 Current vs. Expected Behavior Matrix
| Financial Dimension | Current Behavior (`buyonly`) | Target Behavior (Bidirectional / Short-Selling) |
| :--- | :--- | :--- |
| **Position States** | $\text{marketpostion} \in \{0, 1\}$ | $\text{marketpostion} \in \{-1, 0, 1\}$ |
| **Open Long ($0 \to 1$)** | Entry: $P \times (1 + \text{slip})$, Buy Fee deducted | Entry: $P \times (1 + \text{slip})$, Buy Fee deducted |
| **Close Long ($1 \to 0$)** | Exit: $P \times (1 - \text{slip})$, Sell Fee deducted, PnL = $(P_{\text{exit}} - P_{\text{entry}}) \times \text{size}$ | Exit: $P \times (1 - \text{slip})$, Sell Fee deducted, PnL = $(P_{\text{exit}} - P_{\text{entry}}) \times \text{size}$ |
| **Open Short ($0 \to -1$)** | **Unsupported** (Treated as flat or ignored) | Entry: $P \times (1 - \text{slip})$, Sell Fee deducted |
| **Cover Short ($-1 \to 0$)** | **Unsupported** | Exit: $P \times (1 + \text{slip})$, Buy Fee deducted, PnL = $(P_{\text{entry}} - P_{\text{exit}}) \times \text{size}$ |
| **Unrealized PnL** | $(P_{\text{current}} - P_{\text{entry}}) \times \text{size}$ (only when pos=1) | $\text{marketpostion} \times (P_{\text{current}} - P_{\text{entry}}) \times \text{size}$ |
| **Order Signal Format** | `shiftorder` values $\in \{-1, 0, 1\}$ | `shiftorder` values $\in \{-1, 0, 1\}$ (1=Buy, -1=Sell, 0=Hold) |

## 3. Implementation Checklist & Detailed Blueprint

### 3.1 State Transitions Table
The incoming `shiftorder` signal contains values in $\{-1, 0, 1\}$:
- `1` = Buy signal
- `-1` = Sell signal
- `0` = Hold / Neutral

| Current Position (`last_pos`) | Signal (`current_order`) | Next Position (`pos`) | Trading Meaning | Slippage Applied | Fee Incurred |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **`0` (Flat)** | `1` (Buy) | **`1` (Long)** | Open Long | $P \times (1 + \text{slip})$ | Buy Fee |
| **`0` (Flat)** | `-1` (Sell) | **`-1` (Short)** | Open Short | $P \times (1 - \text{slip})$ | Sell Fee |
| **`0` (Flat)** | `0` (Hold) | **`0` (Flat)** | Neutral | None | None |
| **`1` (Long)** | `-1` (Sell) | **`0` (Flat)** | Close Long | $P \times (1 - \text{slip})$ | Sell Fee |
| **`1` (Long)** | `1` (Buy) | **`1` (Long)** | Duplicate Buy (Hold) | None | None |
| **`1` (Long)** | `0` (Hold) | **`1` (Long)** | Hold Long | None | None |
| **`-1` (Short)** | `1` (Buy) | **`0` (Flat)** | Cover Short | $P \times (1 + \text{slip})$ | Buy Fee |
| **`-1` (Short)** | `-1` (Sell) | **`-1` (Short)** | Duplicate Sell (Hold) | None | None |
| **`-1` (Short)** | `0` (Hold) | **`-1` (Short)** | Hold Short | None | None |

### 3.2 Step-by-Step Task Checklist
- [x] **Task 1: Update `get_entryprice`**
  - Add branch for Short entry: when `marketpostion == -1 and last_marketpostion == 0`, `entryprice = target_price * (1 - slippage)` (or `target_price` if slippage is 0).
- [x] **Task 2: Update `get_exitsprice`**
  - Add branch for Short exit (covering): when `marketpostion == 0 and last_marketpostion == -1`, `exitsprice = target_price * (1 + slippage)` (or `target_price` if slippage is 0).
- [x] **Task 3: Update `get_buy_Fees` and `get_sell_Fees`**
  - `get_buy_Fees`: charged when entering Long ($0 \to 1$) OR covering Short ($-1 \to 0$).
  - `get_sell_Fees`: charged when entering Short ($0 \to -1$) OR closing Long ($1 \to 0$).
- [x] **Task 4: Update `get_OpenPostionprofit`**
  - Calculate unrealized PnL:
    ```python
    if marketpostion == 1:
        OpenPostionprofit = (Close - entryprice) * buy_sizes
    elif marketpostion == -1:
        OpenPostionprofit = (entryprice - Close) * sell_sizes
    else:
        OpenPostionprofit = 0.0
    ```
- [x] **Task 5: Update `get_ClosedPostionprofit` & `get_profit`**
  - In `get_ClosedPostionprofit`:
    - Long close ($1 \to 0$): profit addition = `(exitsprice - last_entryprice) * sizes - sell_Fees`
    - Short cover ($-1 \to 0$): profit addition = `(last_entryprice - exitsprice) * sizes - buy_Fees`
  - In `get_profit`:
    - Long close ($1 \to 0$): `profit = exitsprice * sizes - last_entryprice * sizes`
    - Short cover ($-1 \to 0$): `profit = last_entryprice * sizes - exitsprice * sizes`
- [x] **Task 6: Update `get_order`**
  - Properly reflect transitions involving $-1, 0, 1$:
    - When `marketpostion[i] != marketpostion[i-1]`:
      - $0 \to 1$: `order = 1` (Buy to open)
      - $1 \to 0$: `order = -1` (Sell to close)
      - $0 \to -1$: `order = -1` (Sell to open short)
      - $-1 \to 0$: `order = 1` (Buy to cover)
- [x] **Task 7: Update `logic_order` loop**
  - Implement full state machine respecting current position and signal.
  - Correctly accumulate `all_Fees`, `Gross_profit`, `Gross_loss`, and `netprofit`.
